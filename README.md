# 🛡️ CyberShield – Cybersecurity Incident Reporting System

## 📌 Project Overview
CyberShield is a Python-based web application developed using Flask and MySQL. It helps users report, view, manage, and track cybersecurity incidents through a simple web interface.

## 🚀 Features
- User Registration and Login
- User Authentication
- Report Cybersecurity Incidents
- View Incident Details
- Edit and Delete Incident Reports
- Dashboard for Incident Management
- MySQL Database Integration
- Basic Input Validation

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** MySQL
- **Database Server:** XAMPP
- **Version Control:** Git and GitHub
